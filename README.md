## 📖 About This Repository

This repository contains a curated set of exercises and problems from the **Engineering Probability & Statistics** curriculum. Each problem includes a plain-text description and is solved using both **Python** and **R** to provide practical, computational insights into statistical theory.

The goal is to bridge the gap between mathematical formulas and real-world coding implementation.

## 📚 Syllabus / Table of Contents

- [Chapter 1: Probability Basics (Sets, Events, Axioms)](chapters/01-probability-basics/)
- [Chapter 2: Random Variables (Discrete & Continuous)](chapters/02-random-variables/)
- [Chapter 3: Probability Distributions (PDF, CDF, PMF)](chapters/03-distributions/)
- [Chapter 4: Law of Large Numbers & Central Limit Theorem](chapters/04-lln-clt/)
- [Chapter 5: Inferential Statistics (Confidence Intervals, Hypothesis Testing)](chapters/05-inferential-stats/)

*(More chapters will be added over time)*

## 🛠 Prerequisites

To run the code locally, ensure you have the following installed:

- **Python**: Version 3.8+ with `numpy`, `scipy`, `matplotlib`, and `pandas`.
- **R**: Version 4.0+ with `ggplot2`, `dplyr`, and `tidyr`.

## 🚀 Quick Start

1.  Clone the repository:
    ```bash
    git clone https://github.com/[YOUR_USERNAME]/engineering-probability-statistics.git
    cd engineering-probability-statistics
2. Navigate to a specific chapter folder and read its README.md for the problems.
3. Run the Python scripts or R scripts inside the solutions/ subfolders.
